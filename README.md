Train Tracking API
Overview
The Train Tracking API is a robust and scalable RESTful web service designed to provide real-time information on train locations, routes, and stations. This API aims to enhance the experience of passengers, train operators, and system administrators by offering precise and up-to-date train tracking capabilities. Built using Node.js and Express, with MongoDB as the database, this API ensures high performance, reliability, and easy scalability to meet the demands of modern transportation systems.

Features
1-Real-Time Train Location Tracking: Continuously monitors and updates train locations, providing accurate and timely information to users.
2-Route Management: Allows retrieval and management of train routes, including detailed information about each route and its associated stations.
3-Station Information: Provides comprehensive details about each station, including geographical coordinates and station names.
